# Dashboard Feature (`src/app/features/dashboard`)

This feature provides the primary landing workspace after authentication.

## Included Capabilities

* **KPI Cards**: Summary metric displays using `app-kpi-card` with theme accents.
* **Interactive Visualizations**: Bar and Doughnut charts built with `Chart.js` and PrimeNG `<p-chart>`.
* **Activity Feeds**: Recent system events with PrimeNG `<p-tag>` badges.

## Responsive Design

Uses modern CSS Grid (`repeat(auto-fit, minmax(360px, 1fr))`) ensuring clean layout flow across mobile, tablet, and widescreen viewports.
