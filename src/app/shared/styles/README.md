# Shared Styles (`src/app/shared/styles`)

This directory houses cross-cutting CSS style definitions, specifically theme overrides for PrimeNG component classes.

## Files in this Directory

* **`primeng-shared.css`**: Provides refined padding, border radii, shadows, and hover states for PrimeNG Dialogs, DataTables, Buttons, and Inputs, blending PrimeNG components seamlessly with the design system.
